## 二、安装包 / 源代码包（zip）说明

`7-源代码与安装包.zip` 由 `git archive` 从**已提交的 tracked 文件**生成，
天然排除 `.venv/`、`node_modules/`、缓存与 `*.sqlite` 审计库，且不会出现中文文件名乱码。
`frontend/dist/` 已随仓库下发（LoongArch 麒麟 VM 无 Node 工具链，不在本机构建），开箱即托管。

zip 体积较大且可由仓库随时重生成，故**不纳入 git 版本控制**（见 `.gitignore` 的 `提交物/*.zip`）。
在本分支重新生成：

```bash
git archive --format=zip HEAD \
  backend frontend scripts README.md CLAUDE.md docs/deploy-loongarch.md \
  -o 提交物/7-源代码与安装包.zip
```

部署方式见 `6-安装与部署文档.md`：麒麟 V11 + LoongArch 上 `bash scripts/deploy_kylin.sh --systemd --nginx ...` 一键起服务。
