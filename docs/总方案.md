# 麒麟安全智能运维 Agent —— 开发总方案（软件杯 A2 + 软件工程课程报告）

一套部署在麒麟 OS 上、用自然语言运维 Linux 的智能 Agent，核心卖点是「安全护栏」——能拦住误删库/危险注入并留下可追溯思维链。一套代码同时交付软件杯作品和软件工程课程报告。

## 3. 开发环境配置步骤（Windows 11 + WSL + VM）

你的机器：13900HX / 32G / 4070 Laptop(8G) / 已有 WSL 和 VM。

### 阶段 A：本地主力开发环境（在 WSL2 里，最顺手）

**1) 确认 WSL2 + Ubuntu**
PowerShell（管理员）：
```powershell
wsl --status              # 确认是 WSL2
wsl --install -d Ubuntu-22.04   # 若还没有 Ubuntu
wsl --set-default-version 2
```

**2) WSL 内装基础工具链**
```bash
sudo apt update && sudo apt install -y python3.11 python3.11-venv python3-pip \
     git curl build-essential lsof net-tools iproute2
# Node（前端）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

**3) 装 Claude Code**
```bash
npm install -g @anthropic-ai/claude-code
# 首次运行会引导登录授权
claude
```
> Claude Code 在 WSL 里跑最自然（它本就为类 Unix 环境设计）。在项目根目录运行 `claude`，它会自动读取 CLAUDE.md 和 .claude/skills/。

**4) 本地大模型 Ollama + Qwen3（用于答辩离线演示）**
GPU 加速建议装 Windows 版 Ollama（能直接用 4070），WSL 通过 `host.docker.internal` 或 Windows 主机 IP 访问；或 WSL 内装 Ollama（需配 CUDA on WSL）。简单起见先用 Windows 版：
```powershell
# Windows 端装 Ollama 后
ollama pull qwen3:8b
ollama serve
```
WSL 里把 `OLLAMA_BASE_URL` 指向 Windows 主机：
```bash
# 查 Windows 主机 IP（WSL2）
cat /etc/resolv.conf | grep nameserver
# 通常用 http://<那个IP>:11434/v1
```
> 8GB 显存跑 qwen3:8b（Q4 量化约 5GB）流畅。若想更稳可试 qwen3:4b。32G 内存足够。

**5) 拉起项目骨架**
把本方案附带的脚手架放到 `~/kylin-ops-agent/`，然后：
```bash
cd ~/kylin-ops-agent/backend
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # 填入 DEEPSEEK_API_KEY
```

**6) 让 Claude Code 开干**
在项目根 `claude`，第一句可以是：
> 读 CLAUDE.md 和 roadmap.md，按第1周任务，先把 FastAPI 骨架、LLM 双模式抽象层和 3 个只读 MCP 工具的最小闭环搭起来，每个工具配 pytest。

### 阶段 B：麒麟部署验证环境（VM，后期用）

**1) 申请官方虚机**：QQ 群 1092135086 群文件里有 LoongArch+麒麟 V11 虚机申请说明，**第一周就去申请**（排队要时间）。

**2) 若官方虚机是远程的**：用 VS Code Remote-SSH 或直接 ssh 进去，把代码部署上去做适配测试。LoongArch 上 Python 包可能要从源码编译，留足时间。

**3) 本地 VM 兜底**：你已有 VMware/VirtualBox，可先装一个**麒麟桌面版/服务器版 x86 体验版**练习部署流程（架构不同但 OS 行为接近），等官方 LoongArch 虚机到手再做最终适配。

> 注意：开发全程在 x86 WSL 完成，麒麟只做"部署适配 + 录最终演示"。因为麒麟是标准 Linux 发行版，psutil、lsof、journalctl 这些都在，迁移成本主要在 LoongArch 的包编译。

### 阶段 C：前端
```bash
cd ~/kylin-ops-agent/frontend
npm create vite@latest . -- --template vue
npm install element-plus axios
npm run dev
```

## 4. Claude Code 怎么用最高效

1. **每个新会话先让它读 CLAUDE.md**：项目纲领、评分映射、技术栈、红线都在里面。
2. **触发 skills**：写工具说"按 mcp-tool-builder"，写护栏说"按 safety-guardrail"，写报告说"按 se-report-docx"。Claude Code 会自动加载对应 SKILL.md。
3. **小步快跑**：一次只让它做 roadmap 里的一项，做完让它跑 pytest 验证，再更新 dev-log。
4. **测试先行**：让它"先写测试再写实现"，pytest 用例直接变成课程报告第5章和软件杯测试报告。
5. **每完成一块让它写 docs/dev-log.md**：记录设计/踩坑/解决 → 课程报告"总结"章节素材，零额外成本。
6. **最后阶段让它用 se-report-docx skill 生成 Word 报告**：≥15页、合工大格式、UML 图插入、参考文献规范。
