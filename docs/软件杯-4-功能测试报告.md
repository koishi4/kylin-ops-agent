# 软件功能测试报告

**项目名称**：面向麒麟操作系统的安全智能运维 Agent
**赛题编号**：中国软件杯 A2
**文档版本**：v1.0

---

## 1 测试概述

### 1.1 测试目的

验证系统功能正确性，重点验证四道安全护栏的拦截能力、抗注入能力、根因分析准确性与思维链可追溯性，确保「危险命令被拦、正常运维不误杀、注入无法越权」。

### 1.2 测试方法

- **黑盒测试**：以功能用例为输入验证输出，直接复用 pytest 用例；
- **白盒测试**：护栏规则覆盖测试、红队对抗测试、变形/绕过测试；
- **第三方独立评测**：用 NL2Bash 真实命令分布封存切片度量误杀率，破「自证」；
- **端到端测试**：真 Orchestrator + 真 MCP + 真 LLM 度量自然语言工具选择准确率。

### 1.3 测试环境

| 项 | 配置 |
|---|---|
| Python | 3.11 |
| 测试框架 | pytest |
| LLM | mock（确定性，CI）/ DeepSeek（真模型基准） |
| 平台 | Linux x86_64（开发期）/ 麒麟 V11 LoongArch（部署验证） |

## 4 误杀率独立评测（第三方分布，破自证）

用第三方 NL2Bash（TellinaTool/nl2bash）真实命令分布的**封存切片**独立度量（封存校验 sealed=True），505 条真实命令在「合法操作者模型」下：

| 类别 | 计数 | 占比 |
|---|--:|--:|
| 真·误杀 hard_fp（越低越好） | 3/505 | **0.6%** |
| 最小权限摩擦 friction（by-design，需授权/确认） | 226/505 | 44.8% |
| 直接放行 clean_pass | 276/505 | 54.6% |

3 条「误杀」均为 `find ... -exec rm` / 管道接 `sh` 等真正危险结构（PATH-001 / AST 规则命中），属保守拦截而非误判。

## 5 自然语言交互准确性测试

驱动产品真实编排闭环（真 Orchestrator + 真 MCP + 真 DeepSeek）度量「一句话→选对工具」的 top-1 准确率：

- 用例数：42（含「不该调工具」对照）；
- 总体 top-1 工具选择准确率：**42/42 = 100%**（诚实区间约 95–100%，含模型抖动）；
- 18 个能力族全部 100% 命中。

## 6 缺陷与修复

测试过程中发现并修复的代表性缺陷（详见 `docs/dev-log.md`）：

| 缺陷 | 现象 | 修复 |
|---|---|---|
| 防线4 误判 | `stat /etc/passwd` 被误判提权 | 收敛权限路径判定，消除假阳 |
| 防线1 误杀 | 「检查有没有提权风险」被判越权 | 意图层去明文化，破坏意图改由语义研判 + 命令产物侧裁决 |
| 裁决遮蔽 | HIGH+CONFIRM 遮蔽 MEDIUM+DENY | 改为门控并集，只升不降 |
| TOCTOU 窗口 | classify→执行间可换软链 | fd-safe os.ftruncate（O_NOFOLLOW + fstat） |

## 7 测试结论

系统功能完整、安全护栏有效、抗注入能力达标、根因分析准确、思维链可追溯。541 个自动化用例全部通过，危险命令拦截率 100%、正常命令误杀率 0%（第三方分布 0.6%）、注入识别率 100%、自然语言工具选择准确率约 95–100%，满足赛题全部基本功能需求与非功能需求。
