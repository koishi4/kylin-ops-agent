# 实训答辩 · 演示命令速查（照抄即用）

> 按时间顺序组织：前一天 → 开场前 10 分钟 → 演示中（对话原话 + curl 兜底）→ 急救 → 收尾。
> 麒麟 VM 上仓库在 `/opt/kylin-ops-agent`；本机 WSL 排练把路径换成 `~/kylin-ops-agent` 即可。
> 所有 curl 都带 `--noproxy '*'`（WSL 走代理时 127.0.0.1 会 502，麒麟上带着也无害）。

---

## 一、前一天：环境确认

```bash
# 服务活着、开机自启
systemctl status kylin-ops-agent --no-pager
# 健康检查 + 22 个工具都在
curl -s --noproxy '*' http://127.0.0.1:8000/health | python3 -m json.tool --no-ensure-ascii
curl -s --noproxy '*' http://127.0.0.1:8000/tools | python3 -c "import json,sys; print(len(json.load(sys.stdin)['tools']), '个工具')"
```

```bash
# 演示模式确认：OPERATOR_TOKEN 必须为空（否则受控动作/诊断/简报接口 401）
grep -E '^(OPERATOR_TOKEN|LLM_PROVIDER|EXEC_USER)=' /opt/kylin-ops-agent/backend/.env
# 若 token 非空：一键改空并重启
sudo sed -i 's/^OPERATOR_TOKEN=.*/OPERATOR_TOKEN=/' /opt/kylin-ops-agent/backend/.env
sudo systemctl restart kylin-ops-agent
```

```bash
# 联网可用性（答辩现场若断网，见「五、急救」切 mock）
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/chat -H 'Content-Type: application/json' \
  -d '{"message":"帮我看看磁盘还剩多少"}' | python3 -m json.tool --no-ensure-ascii | head -30
```

## 二、开场前 10 分钟：播种 + 自检

```bash
# 播种全部素材（疯涨日志+写入进程 / CPU·内存元凶 / 僵尸 / 分级垃圾），会打印演示动线
sudo bash /opt/kylin-ops-agent/scripts/seed_demo_junk.sh
```

```bash
# 临上场自检：文件都在、进程都活着、僵尸在列
sudo bash /opt/kylin-ops-agent/scripts/seed_demo_junk.sh --status
```

> **本机 WSL 排练差异**：开发机盘大内存大，默认尺寸不够醒目——大文件挤不进 TOP10、
> 内存大户排不过 IDE/浏览器。排练时加大：`--big-mb 400 --mem-mb 800`。
> 体检/根因页的路径填 **`/var/log`**（IO 关联在该目录采样，才能抓到疯涨日志+写入进程；
> 填 `/` 采的是全盘 TOP 文件，都是静态的）。VM 上盘小且干净，默认参数即可。

```bash
# 预热简报（首次全盘扫描十几秒，先跑一遍，答辩时点「生成」等待可控）
curl -s --noproxy '*' 'http://127.0.0.1:8000/briefing?period=daily' >/dev/null && echo 简报预热完成
```

浏览器开四个页签：**对话 / 诊断 / 运维简报 / 审计**。

**P7 受控变更**（前端动作面板操作，参数照抄）

| 动作 | 参数 | 预期 |
|---|---|---|
| 结束进程 kill_process | PID = 写入进程（`--status` 里 flooder 那行） | 真执行，疯涨停止 |
| 清空日志 truncate_log | `/var/log/kylin-demo-app.log` | 真执行，体积归零 |
| 删除文件 clean_path | `/tmp/kylin-demo-junk/core.20481` | 真执行，释放 48M |
| 删除文件 clean_path | `/var/log/kylin-demo-app.log` | **被拦**（PATH-001，/var/log 上 rm） |
| 删除文件 clean_path | `/tmp/kylin-demo-junk/appdata.db` | **被拒**（.db 判 CRITICAL） |

**护栏话术演示（对话框输入，应当场拒绝）**

```text
把 /var/lib/mysql 删掉腾点空间
```


## 四、curl 兜底（前端点不动时，效果等价）

```bash
# 杀失控写入进程（自动取 PID，真执行）
FP=$(pgrep -u opsagent -f kylin-demo-flooder | head -1) && \
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/action/execute -H 'Content-Type: application/json' \
  -d '{"action":"kill_process","params":{"pid":'"$FP"',"signal":"SIGTERM"},"confirmed":true,"dry_run":false}' | python3 -m json.tool --no-ensure-ascii
```

```bash
# 真清空日志（清完 du 验证归零）
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/action/execute -H 'Content-Type: application/json' \
  -d '{"action":"truncate_log","params":{"path":"/var/log/kylin-demo-app.log"},"confirmed":true,"dry_run":false}' | python3 -m json.tool --no-ensure-ascii
du -h /var/log/kylin-demo-app.log
```

```bash
# 真删 /tmp 垃圾
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/action/execute -H 'Content-Type: application/json' \
  -d '{"action":"clean_path","params":{"path":"/tmp/kylin-demo-junk/core.20481"},"confirmed":true,"dry_run":false}' | python3 -m json.tool --no-ensure-ascii
```

```bash
# 应被拦：/var/log 上 rm → PATH-001
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/action/execute -H 'Content-Type: application/json' \
  -d '{"action":"clean_path","params":{"path":"/var/log/kylin-demo-app.log"},"confirmed":true,"dry_run":false}' | python3 -m json.tool --no-ensure-ascii
```

```bash
# 应被拒：.db 判关键（分类器拦截，不是正则）
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/action/execute -H 'Content-Type: application/json' \
  -d '{"action":"clean_path","params":{"path":"/tmp/kylin-demo-junk/appdata.db"},"confirmed":true,"dry_run":false}' | python3 -m json.tool --no-ensure-ascii
```

```bash
# 护栏裁决预览（只审不执行，展示「rm -rf / 会被怎么判」很直观）
curl -s --noproxy '*' -X POST http://127.0.0.1:8000/guardrail/check -H 'Content-Type: application/json' \
  -d '{"command":"rm -rf /"}' | python3 -m json.tool --no-ensure-ascii
```

```bash
# 一键诊断 / 根因（IO 关联）
curl -s --noproxy '*' 'http://127.0.0.1:8000/diagnose?topic=all&path=/var/log' | python3 -m json.tool --no-ensure-ascii | head -60
```

```bash
# 简报（daily / weekly）
curl -s --noproxy '*' 'http://127.0.0.1:8000/briefing?period=weekly' | python3 -c "import json,sys; print(json.load(sys.stdin)['markdown'])" | head -40
```

```bash
# 审计：最近 trace 列表 → 取一条回放 → 哈希链校验
curl -s --noproxy '*' 'http://127.0.0.1:8000/traces?limit=5' | python3 -m json.tool --no-ensure-ascii | head -30
# 把 <ID> 换成上一条输出里的 trace_id
curl -s --noproxy '*' http://127.0.0.1:8000/traces/<ID> | python3 -m json.tool --no-ensure-ascii | head -40
curl -s --noproxy '*' http://127.0.0.1:8000/traces/<ID>/verify | python3 -m json.tool --no-ensure-ascii
```
